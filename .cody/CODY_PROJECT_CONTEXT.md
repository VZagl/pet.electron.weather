# Контекст этого проекта для AI помощника Cody (Sourcegraph)

## Описание проекта

Pet-проект погодного приложения на Electron с использованием современных веб-технологий.

## Структура проекта

### Основные директории

- `/src/` - исходный код приложения
  - `/src/main/` - основной процесс Electron
  - `/src/renderer/` - процесс рендеринга (UI)
  - `/src/preload/` - preload скрипты для безопасного взаимодействия
- `/build/` - собранные файлы
- `/resources/` - ресурсы приложения (иконки, изображения)
- `/data/` - данные приложения (настройки, кэш API)
- `/data/locales/` - файлы локализации (i18n)
- `/cache/` - кэш приложения

### Конфигурационные файлы

- `package.json` - зависимости и скрипты проекта
- `electron-builder.json` - конфигурация сборки приложения
- `tsconfig.json` - конфигурация TypeScript
- `.eslintrc.js` - правила линтинга кода

## Технологический стек

- **Electron** - фреймворк для создания десктопных приложений
- **TypeScript** - типизированный JavaScript
- **HTML/CSS/JavaScript** - веб-технологии для UI
- **Node.js** - серверная среда выполнения
- **Weather API** - внешний API для получения погодных данных

## Основные функции

- Получение текущей погоды
- Прогноз погоды на несколько дней
- Поиск погоды по городам
- Сохранение избранных локаций
- Настройки единиц измерения (°C/°F)
- Локализация интерфейса

## Архитектура Electron

- **Main Process** - управляет жизненным циклом приложения и создает renderer процессы
- **Renderer Process** - отображает пользовательский интерфейс
- **Preload Scripts** - обеспечивают безопасное взаимодействие между main и renderer процессами

## API и внешние сервисы

- Использование погодных API (OpenWeatherMap, WeatherAPI и т.д.)
- Геолокация для определения текущего местоположения
- Кэширование данных для офлайн работы

## Сборка и развертывание

- Использование electron-builder для создания установочных пакетов
- Поддержка Windows, macOS, Linux
- Автоматическое обновление приложения

## Особенности разработки

- Разделение кода на модули
- Использование современных ES6+ возможностей
- Типизация с помощью TypeScript
- Линтинг и форматирование кода
- Hot reload для быстрой разработки
